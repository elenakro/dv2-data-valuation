# Data OOB

## 1. Περιγραφή

Ο φάκελος περιλαμβάνει την υλοποίηση και τη δοκιμή της μεθόδου **Data-OOB (Out-of-Bag Data Valuation)** με τη βιβλιοθήκη `pyDVL`.

Η μέθοδος χρησιμοποιεί μοντέλα Bagging και αξιολογεί κάθε δείγμα εκπαίδευσης με βάση τις προβλέψεις μοντέλων στα οποία το συγκεκριμένο δείγμα δεν συμμετείχε στην εκπαίδευση (out-of-bag).

Στην παρούσα υλοποίηση χρησιμοποιείται ως βασικός ταξινομητής η `LogisticRegression`. Η `compute_data_oob()` της pyDVL δημιουργεί εσωτερικά το μοντέλο Bagging. Για αυτόν τον λόγο περνάμε στη `Utility` απευθείας τη `LogisticRegression` και όχι ένα ήδη τυλιγμένο `BaggingClassifier`.

## 2. Περιεχόμενα φακέλου

- `calculate_data_oob.py`: Περιέχει τη συνάρτηση `calculate_data_oob()`, η οποία προετοιμάζει το dataset και το μοντέλο, εκτελεί τον υπολογισμό Data-OOB και επιστρέφει τις τιμές, τους μετρητές αξιολόγησης και τον χρόνο εκτέλεσης.
- `test_data_oob.py`: Δημιουργεί ένα συνθετικό dataset, εκτελεί μια αρχική αξιολόγηση Logistic Regression και δοκιμάζει τη λειτουργία Data-OOB.

## 5. Παράμετροι υπολογισμού

Η συνάρτηση `calculate_data_oob()` δέχεται τις εξής βασικές παραμέτρους:

| Παράμετρος | Περιγραφή | Προεπιλογή |
|---|---|---:|
| `X_train` | Χαρακτηριστικά εκπαίδευσης | — |
| `y_train` | Ετικέτες εκπαίδευσης | — |
| `X_test` | Χαρακτηριστικά συνόλου ελέγχου | — |
| `y_test` | Ετικέτες συνόλου ελέγχου | — |
| `n_estimators` | Πλήθος estimators του Bagging | 100 |
| `max_samples` | Ποσοστό δειγμάτων που χρησιμοποιείται ανά estimator | 0.8 |
| `random_state` | Seed για αναπαραγωγιμότητα | 42 |
| `n_jobs` | Πλήθος παράλληλων εργασιών | 1 |

## 6. Επιστρεφόμενα αποτελέσματα

Η `calculate_data_oob()` επιστρέφει dictionary με:

- `values`: τιμή Data-OOB για κάθε δείγμα.
- `counts`: πλήθος OOB αξιολογήσεων ανά δείγμα.
- `indices`: δείκτες των δειγμάτων στα οποία αντιστοιχούν οι τιμές.
- `execution_time`: συνολικό χρόνο εκτέλεσης σε δευτερόλεπτα.
- `result`: το αρχικό αντικείμενο `ValuationResult` της pyDVL.

Στην προεπιλεγμένη λειτουργία ταξινόμησης, η OOB αξιολόγηση βασίζεται στην ορθότητα της πρόβλεψης ανά δείγμα. Επομένως, υψηλότερη τιμή υποδηλώνει ότι το δείγμα ταξινομήθηκε σωστά συχνότερα από τα μοντέλα που δεν το χρησιμοποίησαν στην εκπαίδευσή τους.

Χαμηλή τιμή Data-OOB μπορεί να αποτελεί ένδειξη για περαιτέρω διερεύνηση, αλλά **δεν αποδεικνύει από μόνη της ότι η ετικέτα ενός δείγματος είναι λανθασμένη**.

## 9. Σημειώσεις

- Τα `FutureWarning` που εμφανίζονται κατά την εισαγωγή της pyDVL είναι προειδοποιήσεις της βιβλιοθήκης και δεν εμπόδισαν την επιτυχή εκτέλεση της αρχικής δοκιμής.
- Η παράμετρος `n_estimators` και το `max_samples` πρέπει να επιλέγονται έτσι ώστε κάθε δείγμα να έχει επαρκείς OOB αξιολογήσεις.
- Πριν από την ανάλυση των τιμών πρέπει να ελέγχεται ότι τα `counts` είναι θετικά για όλα τα δείγματα.
